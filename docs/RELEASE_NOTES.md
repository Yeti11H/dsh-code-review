# dsh-code-review 0.1.0 · 首个公开试用版

给 DeepSeek Harness 增加一套可以追溯证据、记住修复历史的代码审查流程。

在 Harness 中描述这次需求和必须遵守的业务规则，调用 `start_review`。插件读取 Git 改动，先找疑点，再回到源码逐项核查。修复后调用 `recheck`，原问题保留编号，报告记录每轮变化。

## 下载哪个文件

- **dsh-code-review-0.1.0.tgz**：可安装的插件包。先下载，再按 README 的“使用交付的安装包”安装。
- **dsh-code-review-source.zip**：完整源码、测试、案例和编译产物，适合自己修改。
- **SHA256SUMS.txt**：两个下载文件的 SHA-256 校验值。

需要 Node.js 24.9.0 或更高版本、Git，以及在 Harness 中配置可用模型。固定适配 Harness `0.2.2-rc.1`。

## 已验证

- 39 项测试通过，1 项因 Windows 符号链接权限跳过。
- 官方 Harness Web 成功启动并加载插件。
- 独立目录安装 `.tgz`，四个工具在官方运行时注册成功。
- 并发示例运行真实代码，复现并修复旧版本覆盖新版本的问题。

## 当前边界

这是试用版，尚未调用真实 DeepSeek 模型测量检出率、误报率或费用。测试中的模型结果由本地适配器提供。代码引用校验不等于推理正确；报告完成也不等于批准合并。

第一版使用文本与导入关系补充上下文，没有完整 AST 或跨语言调用图。默认不修改源码、不执行测试。完整行为与限制见 README 和 `docs/VALIDATION.md`。
